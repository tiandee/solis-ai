# 实施方案 v6: Iterative Pseudo Labeling (迭代伪标签)

## 背景
- **v5 成果**: Pseudo Labeling (Round 1) 取得了 **LB 442.99** 的好成绩。
- **策略**: 使用 v5 的 442.99 预测结果作为更高质量的伪标签，进行第二轮迭代训练。

## 执行结果

### CV MAE 对比
| 模型 | v5 Pseudo | v6 Iterative | 变化 |
| :--- | :--- | :--- | :--- |
| LightGBM | 466.19 | **464.07** | 📉 -2.1 |
| XGBoost | 471.73 | 472.53 | 📈 +0.8 |
| CatBoost | **463.44** | 472.88 | 📈 +9.4 |

### 线上成绩 (LB)
- 提交文件: `predictions_pseudo_v6.csv`
- **分数**: **444.97** (不如 v5 的 442.99)

## 结论 (2026-02-13) ❌

### 失败原因分析
1.  **CatBoost 显著退步** (463 -> 473): v6 CatBoost 使用了默认的 RMSE Loss，且降低了正则化 (`l2_leaf_reg=3`)，导致对伪标签中的噪声更敏感，出现过拟合。
2.  **边际效应递减**: 第二轮 Pseudo Label 的增益很小（LGB 仅提升 2 分），而噪声的累积效应开始显现。伪标签本身不完美，多轮迭代会放大这些"错误"。
3.  **融合权重未优化**: 使用了固定的 0.4/0.2/0.4 权重，但 v6 各模型的相对强弱已发生变化。

### 最终结论
- **Best Score**: **v5 (LB 442.99)** 仍然是最佳成绩。
- **v6 迭代伪标签未能进一步提升**，确认了伪标签策略的收益上限。
