# 实施方案 v4: 直接 MAE 优化 (冲刺 400 分)

## 背景 (Context)
当前最佳成绩: **445.64**
我们之前的尝试 (v2: 多模型融合, v3: Stacking) 在 445 分左右陷入瓶颈。分析表明，我们一直沿用的 **对数变换 (Log-transform)** 策略（优化的是相对误差 MSLE）可能与比赛的评估指标 **MAE (平均绝对误差)** 不完全对齐。

## 核心假设 (The Hypothesis)
- **对数变换的问题**: 它优化的是百分比误差。例如，预测 100,000 的车误差 10% (差 10,000) 和预测 2,000 的车误差 10% (差 200)，在 Log 空间下的 Loss 是一样的。
- **MAE 指标的特性**: 它优化的是绝对金额误差。预测 100,000 的车如果误差 10,000，其惩罚是 2,000 的车误差 200 的 **50倍**！
- **策略**: 移除对数变换，直接基于原始 `price` 进行训练，并使用 L1 (MAE) 作为损失函数。这样模型会自然地更关注那些“高价且容易预测错”的样本，从而大幅降低整体 MAE。

## 改动计划 (Proposed Changes)

### 1. 新训练脚本: `code/train_direct_mae.py`
基于 `train_optimized.py` 进行修改，核心变化如下：
- **目标变量**: 使用原始 `price`，**不再使用** `np.log1p(price)`。
- **损失函数 (Objectives)**:
    - LightGBM: `objective='regression_l1'` (MAE)
    - XGBoost: `objective='reg:absoluteerror'` (MAE)
    - CatBoost: `loss_function='MAE'`
- **评估指标**: 直接监控原始 MAE。

### 2. 风险控制
- **方差过大**: 原始价格范围很大 (10 ~ 90,000+)，可能导致梯度更新不稳定。
- **缓解措施**: 
    - GBDT 对数值范围通常比较鲁棒。
    - 如果训练不稳定，可以考虑对极值 (如 > 99.5% 分位数) 进行截断。

### 3. 执行步骤
1. 实现 `train_direct_mae.py`。
2. 优先训练 LightGBM (验证速度最快)。
3. 如果 CV 分数显著下降 (如 < 440)，则继续训练 XGBoost 和 CatBoost。
4. 对 "Direct MAE" 系列模型进行融合。

## 验证计划 (已完成)
- 对比 `train_direct_mae.py` 与 `train_optimized.py` (CV ~480) 的单模型 CV 分数。

## 结论 (2026-02-13 验证失败) ❌

### 实验结果
- **LightGBM (MAE Objective)**:
    - 初始参数 (LR=0.03): 收敛极慢，1000轮后 MAE 仍 > 500。
    - 高学习率 (LR=0.10): 收敛加快，但出现严重过拟合 (Train MAE 322 vs Valid MAE 516)。
    - 正则化优化 (LR=0.05, Leaf=31, Reg=10): 缓解了过拟合，但最终收敛 MAE 约为 **496**。

### 失败原因分析
1.  **目标变量分布偏斜**: 二手车价格呈现严重的长尾分布 (Long-tail)。直接在原始空间优化 MAE，导致模型过度关注极少数的高价样本（Outliers），而忽略了占大多数的中低价样本。这使得梯度的方差极大，模型难以找到全局最优解。
    -   *相比之下，Log 变换后的目标变量近似正态分布，梯度更稳定，且天然压制了高价样本的权重，使得模型能学到更普适的规律。*
2.  **L1 Loss 的优化难度**: L1 Loss 的梯度是常数 (±1)，在接近零点时不平滑，且不像 MSE (L2) 那样在误差大时提供巨大的梯度指引（虽然这对 MAE 是好事，但也意味着收敛变慢）。

### 下一步决策
-   **放弃** Direct MAE 策略。
-   **回归** Log-target 策略 (v2/v3)。
-   **启用 v5 方案**: Pseudo Labeling (伪标签)，利用 LB 445 的预测结果扩充训练集，进一步提升模型泛化能力。
